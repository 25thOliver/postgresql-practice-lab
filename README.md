# PostgreSQL Practice Lab

A hands-on SQL practice environment using PostgreSQL, Docker Compose,
and synthetic business data.

## Objectives

- Practise SQL through original, progressively difficult exercises.
- Learn query patterns by solving problems independently.
- Explore realistic datasets and edge cases.
- Document approaches, mistakes, and lessons learned.
- Build practical SQL skills relevant to data engineering.

## Technology Stack

- PostgreSQL
- Docker and Docker Compose
- Python for synthetic data generation
- Git and GitHub

## Learning Roadmap

1. Filtering and sorting
2. Aggregation and grouping
3. Joins
4. Subqueries
5. Common Table Expressions (CTEs)
6. Conditional logic and NULL handling
7. Window functions
8. Date and time analysis
9. Data engineering SQL
10. Mixed interview practice

## Security

Local credentials belong in `.env`, which must never be committed.
Use `.env.example` as the configuration template.
